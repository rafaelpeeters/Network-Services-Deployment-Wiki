# Network Services Deployment Wiki

A complete guide and technical documentation for setting up a private cloud infrastructure on Linux.
It covers configuring local networks, managing static and dynamic IP addressing, routing, and user permissions.
The repository walks through deploying Nextcloud and OnlyOffice services using package managers like apt and snap.
It includes full client-side integration via the Nextcloud desktop client and detailed troubleshooting notes.
